# Artifact Manifest Specification

Every rendered artifact includes a machine-readable audit manifest tracking compilation details.

---

## 1. Schema Definitions

```go
type ArtifactManifest struct {
	ArtifactID         string                    `json:"artifact_id"`
	ArtifactType       planning.ArtifactType     `json:"artifact_type"`
	PlanID             string                    `json:"plan_id"`
	PlannerVersion     string                    `json:"planner_version"`
	RendererVersion    string                    `json:"renderer_version"`
	RenderingPolicy    string                    `json:"rendering_policy"`
	SelectedClaimIDs   []claims.ClaimID          `json:"selected_claim_ids"`
	ExcludedClaimCount int                       `json:"excluded_claim_count"`
	RenderedEntryIDs   []string                  `json:"rendered_entry_ids"`
	ClaimToEntryMap    map[claims.ClaimID][]string `json:"claim_to_entry_map"`
	SourceReferences   []string                  `json:"source_references"`
	EvidenceReferences []string                  `json:"evidence_references"`
	Warnings           []string                  `json:"warnings,omitempty"`
	Overrides          []planning.Override       `json:"overrides,omitempty"`
	ContentDigest      string                    `json:"content_digest"`
}
```

---

## 2. Content Digest Rules
*   To ensure determinism, the `ContentDigest` is generated by hashing the concatenated section titles and entry text fields using SHA-256.
*   The resulting hex string changes if any content, spelling, or ordering within the artifact is modified.
*   This makes it easy to detect changes across runs.
