# CKB Examples Directory

This directory provides complete, structured examples of a Career Knowledge Base. These examples are completely fictional and designed to show the relationships, linkages, and completeness expected for an evidence-grounded career generation system.

## Available Examples

### 1. Principal Cloud Architect Profile
The main files in the root of the `ckb/` directory are prepopulated with fictional data representing a Principal Cloud Architect who has worked at Stark Industries, Acme Corp, and CyberDyne. 

You can refer to:
*   [experience/leadership.md](../experience/leadership.md) - Fictional senior management and IC roles.
*   [projects/example-project.md](../projects/example-project.md) - Project Titan and Project Phoenix specifications.
*   [skills.md](../skills.md) - Skill proficiency, years of experience, and last-used metrics.
*   [evidence.md](../evidence.md) - Ground-truth verification links for repositories, design documents, and evaluations.

## How to use this example for your own vault:
1.  Copy the files from [templates/](../templates/) to your private Obsidian vault directory.
2.  Follow the naming and link structure defined in [schema.md](../schema.md).
3.  Replace the fictional fields with your own verified history.
4.  Do NOT commit your personal vault files to public git repositories to protect your PII.
